# 사주 MVP 한계

- 절기 경계: 태양 황경 근사 (실제 공식 절입과 수 시간 차이 가능)
- **진태양시**: 기본 경도 서울(126.978°E), 표준자오선 135°E, 균시차 Spencer 근사. 도시별 경도 입력 가능. 서머타임·고도 미반영.
- **야자시**: 기본 `next_day` — 23:00–23:59 출생 시 일주·시주 경계를 다음날로. `off`로 끌 수 있음. 조자시(00–01)는 당일.
- 시주: 보정된 HH:mm 기준 2시간 지지
- 음력: 1900–2100 공개 비트테이블, 윤달 선택 UI 없음
- 십신: 천간·지지 정기(본기)만
- 지장간: 여기·중기·본기 표 (학파별 표기 차이 가능)
- 대운: 양남음녀/음남양녀 순·역행, 절입 일수÷3 시작 나이 근사, 성별 필요
- **신살**: 도화·화개·역마·공망·천을귀인 (일지/일간 기준 간이). 그 외 신살 미계산
- **전문 명리 아님 — 참고·엔터테인먼트용**
