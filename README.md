# 별빛 타로 — 개인화 타로 MVP

회원가입·온보딩 후, 메이저 아르카나로 **개인화된 타로 리딩**을 받는 한국어 웹 프로토타입입니다.

## 실행 방법

```bash
cd /workspace/personalized-tarot
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

프로덕션 빌드:

```bash
npm run build
npm start
```

## MVP에 포함된 기능

1. **랜딩** — 서비스 소개 (한국어)
2. **회원가입 / 로그인** — 이메일·이름 기반 데모 인증 (`localStorage`)
3. **온보딩 3문항** — 고민 분야 / 기분 / 리딩 목표(통찰·행동·위로)
4. **뽑기** — 섞기 애니메이션 → 1장 또는 3장 스프레드 → 카드 공개
5. **개인화 해석** — 고전 카드 의미 + 온보딩 답변 템플릿 조합 (외부 AI API 없음)
6. **결과 · 기록** — 해석 표시, 로컬 히스토리 저장, 다시 뽑기

### 라우트

| 경로 | 설명 |
|------|------|
| `/` | 랜딩 |
| `/auth` | 회원가입 / 로그인 |
| `/onboarding` | 온보딩 3문항 |
| `/draw` | 카드 뽑기 |
| `/result` | 리딩 결과 (`?id=` 지원) |
| `/history` | 로컬 리딩 기록 |

### 기술 스택

- Next.js App Router + TypeScript + Tailwind CSS
- 상태: `localStorage` (유저, 온보딩, 히스토리)
- 데이터: 메이저 아르카나 22장 (한국어 이름 · 정방향 의미)

## 다음 단계 제안

- **실제 인증**: NextAuth / Clerk / Supabase Auth (OAuth, 매직 링크)
- **DB**: 유저·리딩·온보딩을 Postgres 등에 저장, 기기 간 동기화
- **AI 해석**: LLM API로 카드+컨텍스트 기반 자연어 해석 (키는 서버 사이드)
- **결제 / 멤버십**: 일일 무료 횟수 + 유료 스프레드, Stripe 등
- **카드 확장**: 마이너 아르카나, 역방향, 커스텀 스프레드
- **공유**: 결과 이미지 생성 / 링크 공유

## 참고

- 엔터테인먼트·셀프 리플렉션 목적의 MVP입니다.
- 실제 점술·의료·법률 조언을 대체하지 않습니다.
